An equation is a statement that two things are equal. For example, 2x + 3 = 11 says that "two lots of some number, plus 3" is the same as 11.

A **linear equation** is one of the simplest kinds. The letter (the variable) only appears on its own, never squared, never multiplied by itself, and never on the bottom of a fraction.

## What makes an equation linear

An equation is linear when every variable has a power of 1. That means you see x, but not x², x³ or √x.

Here are some linear equations:

- 2x + 3 = 11
- y = 3x − 2
- x/4 = 5
- 7 − a = 2a + 1

And here are some that are **not** linear:

- x² + 1 = 10 (x is squared)
- 1/x = 2 (x is on the bottom of a fraction)
- √x = 3 (x is under a square root)
- xy = 12 (two variables are multiplied together)

The letter does not have to be x. It can be a, t, n or any other letter. What matters is how it appears.

## Why it is called "linear"

When a linear equation has two variables, like y = 2x + 1, you can draw it as a graph. The points always lie on a straight line. That is where the name comes from.

Try some values of x and see what y is:

| x | y = 2x + 1 |
|---|---|
| 0 | 1 |
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |

Each time x goes up by 1, y goes up by 2. The steady change is what makes the line straight. The 2 in front of x is called the **slope** (how steep the line is), and the + 1 is where the line crosses the y-axis.

## A real-life example

A taxi charges $3 to start the ride plus $2 for every kilometer. If k is the number of kilometers, the cost C is:

C = 2k + 3

This is a linear equation. Every extra kilometer adds the same $2.

### Example: how much does a 5 km ride cost?

1. Put k = 5 into the equation: C = 2 × 5 + 3
2. Multiply first: 2 × 5 = 10
3. Then add: 10 + 3 = 13
4. The ride costs $13.

### Example: how far can you go for $19?

Now you know the cost and want the distance.

1. Write the equation: 2k + 3 = 19
2. Take 3 from both sides: 2k = 16
3. Divide both sides by 2: k = 8
4. You can travel 8 km.

Finding the value of the letter like this is called **solving** the equation. There is a full guide in [how to solve a linear equation](/articles/how-to-solve-a-linear-equation).

## Checking a solution

A solution is a value that makes both sides equal. To check, put it back in.

Is x = 4 a solution of 2x + 3 = 11?

1. Left side: 2 × 4 + 3 = 8 + 3 = 11
2. Right side: 11
3. Both sides are 11, so yes, x = 4 is the solution.

Is x = 5 a solution? Left side: 2 × 5 + 3 = 13. That is not 11, so no.

## How many solutions can there be?

A linear equation with one variable usually has exactly one solution. But there are two unusual cases:

- **No solution.** 2x + 1 = 2x + 5 can never be true. Adding 1 to a number can never give the same result as adding 5 to it.
- **Every number works.** 2(x + 1) = 2x + 2 is true for any x, because both sides are the same thing written differently.

## Mistakes to watch for

- **Thinking any equation with x is linear.** Look at the power. x² = 16 has an x, but it is a [quadratic equation](/articles/what-is-a-quadratic-equation), not a linear one.
- **Forgetting that 3x means 3 × x.** When x = 4, 3x is 12, not 34.
- **Doing the order wrong.** In 2 × 5 + 3, multiply before you add. The answer is 13, not 16.

## Try it yourself

1. Is 5x − 7 = 3 linear? If so, solve it.
2. A gym charges a $20 sign-up fee plus $15 a month. Write the cost after m months, then find the cost for 6 months.

**Answers:** 1) Yes, it is linear. 5x = 10, so x = 2. 2) C = 15m + 20. For 6 months, 15 × 6 + 20 = 110, so $110.
